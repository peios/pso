# PSO test vectors

`pso.vectors` holds chains with the result every verifier must reach for
them. A second implementation, such as a kernel's, is correct when it
agrees with every case.

The file is generated by `pso/tests/vectors.rs` from fixed seeds. Do not
edit it. To write it again after changing the generator:

```sh
PSO_WRITE_VECTORS=1 cargo test -p pso --test vectors
```

## Format

The file is text. A line starting with `#` is a comment. Every other line
is a word, a space, and a value. A case runs from a `case` line to an `end`
line. Bytes are lowercase hexadecimal.

| Word | Value | Occurs |
|---|---|---|
| `case` | The case's name | Once, first |
| `about` | What the case shows | Once |
| `root` | A root the verifier holds: its key type byte, then its key | Any number |
| `toplevel` | A top-level certificate the trust store enables | Any number |
| `intermediate` | A certificate that can be found by its object hash | Any number |
| `revocation` | A revocation the trust store holds | Any number |
| `distrust` | A distrust entry the trust store holds | Any number |
| `recognize` | A warrant name the verifier recognizes | Any number |
| `hash-form` | The hash form the place calls for, one byte | Once |
| `content-hash` | The file's content hash in that form | Once |
| `bundle` | The bundle | Once |
| `expect` | `invalid`, `incomplete`, `refused`, `consistent`, `unrooted` or `rooted` | Once |
| `expect-name` | The leaf's name, for the three results that return it | At most once |
| `expect-refusal` | `revoked` or `distrusted`, for `refused` | At most once |
| `end` | Nothing | Once, last |

A verifier is given the content hash, so no case exercises finding a
bundle in a file or hashing one. No case expects `unsigned`, which a
verifier reports before it has a bundle.
